# loveSID Demo

> **⚠ DEPRECATED!** This repo uses an old version of [loveSID](https://github.com/mstfbil/lovesid) and is no longer maintained. I'm working on a better .sid player ^^

This is a demo project that plays ".sid" *PSID* files using the [loveSID](https://github.com/mstfbil/lovesid) library and love2d framework. Clone and run `love .` and drag a ".sid" file to hear it!
